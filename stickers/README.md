# SolFoundry Sticker Pack

A set of 10 stickers designed for SolFoundry's Telegram/Discord communities, following the brand's neon cyberpunk aesthetic.

## Brand Colors

- **Cyan (#00FFFF)**: Anvil, primary elements
- **Magenta (#FF00FF)**: Hammer, secondary elements  
- **Orange (#FFA500)**: Sparks, fire effects
- **Yellow (#FFFF00)**: Lightning, bright accents
- **White (#FFFFFF)**: Text, highlights
- **Black (#000000)**: Background

## Stickers Included

1. **01_anvil.png** - The iconic SolFoundry anvil (logo variant)
2. **02_hammer.png** - The forge hammer (logo variant)
3. **03_spark.png** - Sparks flying from the forge
4. **04_rocket.png** - Rocket launch (liftoff/beginning)
5. **05_code.png** - Code brackets `{/}` (developer focus)
6. **06_lightning.png** - Lightning bolt (power/speed)
7. **07_heart.png** - Heart (love/support)
8. **08_thumbsup.png** - Thumbs up (approval/agreement)
9. **09_fire.png** - Fire (hot/trending)
10. **10_gear.png** - Gear/cog (building/working)

## Specifications

- **Format**: PNG with transparency
- **Size**: 512x512 pixels
- **Style**: Flat geometric design with neon colors
- **Background**: Transparent (works on dark/light backgrounds)

## Usage

These stickers are designed for:
- Telegram sticker packs
- Discord emoji/stickers
- GitHub reactions
- Community communications

## Design Principles

1. **Consistent Brand Style**: All stickers use SolFoundry's signature neon colors
2. **Simple & Recognizable**: Clean geometric shapes that are clear at small sizes
3. **Developer Culture**: Mix of forge themes and developer memes
4. **High Contrast**: Bright colors on dark background for visibility
